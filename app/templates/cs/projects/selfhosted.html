Doma provozuji vlastní server, na kterém hostuji několik služeb pro osobní použití.

Mezi tyto služby patří:

  • Jellyfin
  • Audiobookshelf
  • TriliumNext
  • Immich

Server, na kterém služby běží, je starší počítač HP s Ubuntu Server 22.04. Jako reverzní proxy používám nginx a služby provozuji v Docker kontejnerech. Abych skryl svou veřejnou IP adresu, používám proxy od Cloudflaru.

Do budoucna bych se rád úplně odpoutal od velkých technologických firem, jako jsou Google a Microsoft, a nahradil jejich produkty open source alternativami, které si hostuji sám. Momentálně si zprovozňuji vlastní mailový server a Nextcloud.
